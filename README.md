# 🤜 KENGAN ARENA: Underground Scout Report

Welcome to the **Yamashita Trading Co.** confidential fighter database. This application is a high-fidelity scout report designed for fans of *Kengan Ashura* and *Kengan Omega* to analyze the lethal fighters of the Kengan Matches and Purgatory.

## ⚡ The Concept

**Kengan Arena** isn't just a database; it's a strategic tool. Whether you're a "Realist" looking at the stats or a fan of the "Niko Style," this app allows you to visualize the overwhelming power, speed, and techniques of the world's strongest martial artists.

## 🛠 Features for the Kengan Fan

- **🔥 Lethal Roster:** Analyze detailed profiles of fighters like Ohma Tokita, Agito Kanoh, and Kuroki Gensai.
- **📊 Visual Skill Matrices:** High-impact progress bars showing Striking, Grappling, Power, Speed, and Endurance.
- **🥋 Secret Techniques:** Catalog of signature moves (Demonsbane, Dragon Shot, Devil Lance, etc.).
- **🤜 VS Mode (Matchup Analytics):** Select two fighters to trigger a head-to-head comparison overlay with stat differentials.
- **🌑 Underground Aesthetic:** A dark, aggressive UI themed with gold and blood-red accents, inspired by the atmosphere of the Kengan domes.

## 🚀 Tech Stack

- **React 19:** Utilizing the latest performance features.
- **Tailwind CSS v4:** Cutting-edge styling with the new engine.
- **Framer Motion:** Smooth, high-impact animations for a cinematic feel.
- **Vite:** Blazing fast development and build times.

## 👣 Getting Started

To run the scout report locally:

1.  **Clone the repo:**
    ```bash
    git clone https://github.com/rodrigopazTech/kengan-arena-mma-database.git
    ```
2.  **Enter the arena:**
    ```bash
    cd kengan-mma
    ```
3.  **Install dependencies:**
    ```bash
    npm install
    ```
4.  **Ignite the server:**
    ```bash
    npm run dev
    ```
